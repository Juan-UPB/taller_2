## Integrantes

* Juan Manuel Castro Vargas

## Descripción

En este taller se trabajan conceptos básicos de programación en Java, como variables, tipos de datos, inicialización, reasignación de valores y estructuras condicionales.

## Objetivos

* Crear variables de diferentes tipos.
* Inicializar variables con valores compatibles.
* Reasignar valores a las variables.
* Utilizar diferentes tipos de datos en Java.
* Trabajar con estructuras condicionales.
* Crear un menú de opciones.
* Utilizar Git y GitHub para el control de versiones.

## Archivos

### Variables.java

Programa en Java que contiene 20 variables de diferentes tipos de datos, con sus respectivos valores iniciales y reasignaciones.

### Condicionales.java

Programa en Java que contiene un menú con tres opciones:

1. Solución de la ecuación 1.
2. Solución de la ecuación 2.
3. Salir.
